# Isenthalpy Studio v6.0
### Plataforma Industrial de Termodinámica & Verificador SMath (Motor NIST CoolProp C++)

Plataforma científica para simulación y validación de ciclos de potencia (Rankine, Brayton), ciclos de refrigeración, análisis exergético bajo la 2ª Ley de la Termodinámica (Kelvin-Planck & Clausius), cálculo de estados termodinámicos IAPWS-95 y visor integrado de literatura técnica.
